COME USARE QUESTO ESEMPIO

1. Apri la cartella Help_HTML_Fetch_Componenti con Visual Studio Code.
2. Installa l'estensione Live Server.
3. Clic destro su index.html.
4. Scegli 'Open with Live Server'.

Nota:
Aprendo index.html direttamente come file locale, alcuni browser possono bloccare fetch().
Con Live Server funziona correttamente.

File principali:
- index.html = pagina principale
- cnc/tnc640.html = pagina figlio
- css/style.css = stile grafico
- js/components.js = carica header/menu/footer
- js/script.js = dark mode e ricerca
- partials/header.html = intestazione comune
- partials/menu.html = indice comune
- partials/footer.html = footer comune
